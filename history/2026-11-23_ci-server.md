## Forgejo 15.0.12 → 17.0.2

Renovate merged the tag bump on 2026-11-21 (`2ade5582`, #324), but it was never
deployed. servyy-test had run 17.0.2 since then, including the whole runny-test
rehearsal of the rootless runner (same runner version, 13.2.1).

### Pre-checks

- **Release notes and upgrade guides (v16, v17):** going 15 → 17 directly is
  supported. Migrations run on start, and a downgrade is refused afterwards.
  None of the breaking changes applies here:
  - reverse-proxy auth trust (v16): not used;
  - mirrors no longer follow redirects (v16): no mirrors;
  - Action-run webhooks deprecated (v17): none configured;
  - repo-relative links in rendered documents (v17): cosmetic.

  The full Codeberg release notes did not load, so this rests on the
  announcements and the upgrade guides.
- **forgejo-runner 13.2.1** is compatible: v17's job summaries need 13.2 or
  newer.

### Steps

```bash
# fresh DB dump (on top of the nightly ones), then flush queues
ssh servy.lehel.xyz 'systemctl --user start forgejo-dump.service'
#   → ./data/backup/forgejo-db-20261123-204202.tar.gz (1.9 MB)
ssh servy.lehel.xyz 'docker exec ci.forgejo forgejo manager flush-queues'   # Flushed

cd ansible && ./servyy.sh --tags user.docker.ci --limit servy.lehel.xyz
#   → ok=166 changed=1 failed=0
```

### Verification

- `GET /api/v1/version` → `17.0.2+gitea-1.22.0`. Container `Up (healthy)`.
- Migrations logged, no errors: the v16a–v16e set (authorized integrations,
  `OIDCSubjectFormat=legacy-forgejo-v15` for actions-enabled repos, granular
  watch, action-run priority) and the v17a set (step summary table, invite
  expiry, job namespace, package cleanup by last download).
- Signed-out `/` still redirects to the sign-in page.
- Runners: `codey` and `runny` both `idle` afterwards, and runny kept label
  `amd64` and `owner_id=1` (scope `cda`). During the restart both logged
  `failed to fetch task` (502, then 405) for about 8 s (20:43:26 → 20:43:34),
  nothing after.

### Known noise

`forgejo doctor check --all` reports
`/var/lib/gitea/data/log: no such file or directory`. Forgejo logs to the
console here, so nothing is lost. Left as is.

### Not yet verified on v17

- No Actions job has run on production v17 yet. The runners poll cleanly, and

- `forgejo/upload-artifact` (v4/v5 fork) on v17. Repeat the F4 check from the
  rootless plan on the first workflow that needs artifacts.

## Other changes today (summaries; details in the linked entries)

- **Job socket revoked** (`59c7d216`): host-backend jobs got the host's root
  Docker socket (`fc422ae3`, briefly live). They now get `docker_host: "-"`.
  This also fixed the `forgejo_runner` molecule asserts, which had been red
  since `fc422ae3`.
- **fail2ban false bans** (`c2fba8ed`): runny was banned three times as a
  crawler for polling. The exclusion is `RequestPath !~ "/api/actions/runner.v1.*"`
  (the gRPC paths have no `/` after `v1`). Proven with an 11-min job at 222
  req/2 min and no ban. codey's count dropped from 182 to 121 per 2 min.
- **runny rootless** (`6b3cba8a`, `eef2c622`): runner binary and rootless dockerd
  run as user services of `runner`, and root-run Docker is masked. All 14
  acceptance checks pass on production. The runner is scoped to `cda` with
  `--keep-labels`.
- **Theme** (`189b9d02` … `5075594e`, PR #347): tracked `ci/custom/`, mounted
  read-only. The sign-in hero needs one full-template override (`signin.tmpl`),
  which is an upgrade risk. The first version squeezed the sign-in card into a
  ~30 px column. It was caught from screenshots and fixed before production.
  Deployed with `--tags user.docker.repo,user.docker.ci`, which also brought
  servy's checkout from `dd97ddb` to `5075594e`.

## Follow-ups

- **codey still runs privileged dind**: a job there can reach codey's host,
  and codey holds the claude-hub and opencode credentials. Needs its own plan
  (rootless next to the root-run daemon, host QEMU binfmt). See
  `docs/plans/2026-11-23_runny-docker-trust.md` §9.
- **v17 is not LTS** (supported until 2027-01-28). Plan the next upgrade, and
  re-check `signin.tmpl` each time.
- **Repo migration** from `git.lehel.xyz` and the GitHub repos with workflows
  has not started.
- **Docs:** CLAUDE.md's "Docker Cleanup" section says weekly on servy/codey,
  but `plays/vars/default.yml` runs it daily at 02:00.
